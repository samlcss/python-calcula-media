# 📊 Cálculo de Média Simples em Python

Script simples desenvolvido para calcular a média aritmética de 3 notas fornecidas pelo usuário.

## 📌 Conceitos Praticados
- Entrada de dados numéricos (`float(input())`).
- Operações aritméticas básicas (soma e divisão).
- Formatação de ponto flutuante com duas casas decimais (`:.2f`).

## 🚀 Como Executar

```bash
python calcula_media.py
```
